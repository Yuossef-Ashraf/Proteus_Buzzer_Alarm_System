## 🎯 What This Does

Electronic circuit schematic and simulation project modeled in Proteus VSM for automated audio alarm triggers, frequency modulation, and buzzer driving circuits.

---

## ✨ Key Features

- PWM-driven Tone & Frequency Synthesis
- Transistorized High-Decibel Buzzer Amplification
- Interactive Button Trigger Simulation
- Complete Proteus Design Suite Project

## 🚀 How to Run & Simulate

1. **Hardware Setup (Arduino Projects):**
   - Open the `.ino` source file in Arduino IDE.
   - Connect your microcontroller board via USB.
   - Select the appropriate COM port and board model.
   - Click **Verify** then **Upload**.

2. **Proteus Simulation (.pdsprj):**
   - Open Proteus Design Suite.
   - Load the `.pdsprj` project file from this repository.
   - Click the **Play / Simulate** button at the bottom-left corner.
   - Interact with buttons, potentiometers, and virtual sensors in real-time.
